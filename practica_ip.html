Ayuda: Tipos de Direcciones IP
  • Privadas: Rangos reservados para redes locales: 10.0.0.0 - 10.255.255.255; 172.16.0.0 - 172.31.255.255; 192.168.0.0 - 192.168.255.255.
  • Públicas: Cualquier IP que no esté en los rangos privados ni especiales. Son ruteables en Internet.
  • Loopback: Rango 127.0.0.0 a 127.255.255.255. Se usa para pruebas locales (localhost).
  • APIPA (Automatic Private IP Addressing): Rango 169.254.0.0 a 169.254.255.255. Windows las asigna cuando no encuentra un servidor DHCP (problema de conexión).
  • Multicast: Rango 224.0.0.0 a 239.255.255.255. Se usan para enviar un solo paquete a un grupo de dispositivos (streaming, protocolos de ruteo).
